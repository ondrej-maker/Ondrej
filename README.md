# Ondrej
Vytvoř offline desktopovou aplikaci pro Windows v českém jazyce určenou k procvičování německých slovíček. Aplikace musí mít oddělenou databázi, aplikační logiku a uživatelské rozhraní.  Hlavní funkce Databáze 1 000 nejdůležitějších německých slov. Správa slovíček a tvorba vlastních okruhů. Zkoušení ČJ ↔ NJ. Trvalé ukládání dat. Databáze
